# umastagram-generator

Inspired from a [Twitter/X post](https://x.com/ogurisan0813/status/2089523422422499368),
which featured a transparent plastic(?) card that allows people to catch photos with their favorite Umamusume.

To note, the original cards can be found in
[online stores](https://tcgrepublic.com/product/text_search.html?page=1&q=Clear+Card+-+Uma+Musume).

## Made with

- React
- Cloudflare Kumo UI
- react-easy-crop
- FontAwesome
